Four outcomes
BLOCKED

The agent gets the reason.

IT: Admin role requested without an approved ticket

Finance: Exact duplicate invoice

PERSON DECIDES

A named person decides. No answer = no.

IT: Access to payroll data outside the agent's role

Finance: Supplier bank details changed

RUNS ALONE

Rules permit, checks clean.

IT: Password reset for a verified user

Finance: Order, goods receipt and invoice match

RECORDED ONLY

Nothing blocked yet.

Every new rule starts here, in IT and finance alike.

Autonomy

Each agent earns its freedom, step by step.

Evidence moves an agent up. Drift, a breach or a model change moves it back. Loosening a rule needs a test on past cases and two signatures.

1
Suggests

The agent proposes. A person acts.

2
Each step approved

The agent acts after a named person says yes.

3
Within limits

Routine actions run alone. Risky ones go to a person.

4
Alone

Earned on evidence, per action. Taken back on drift.

Steps follow progressive autonomy (Hogan, ARE Manifesto v1.0 draft). See How we work.
