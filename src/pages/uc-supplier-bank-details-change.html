The problem

Fake bank-detail changes are a common way to divert supplier payments. One wrong change can send the next payment run to a fraudster. Each change needs a check, a call-back and a named approver.

What the agent does

May
  • Read the request and the supplier record
  • Run your checks: sender, history, open invoices
  • Prepare the change for approval
Never
  • Activate new details without a call-back
  • Use contact data from the request itself
  • Release a payment to new details
