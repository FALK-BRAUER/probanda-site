What it does

Stop. Approve. Prove.

  • Named rule, not a guess
  • Prompt injection refused
  • Kill switch: the agent stops, not the business

Approve

Four controls

Every auditor asks the same four things.

1

Know your agents

Inventory read from your identity platform or agent registry. Unknown agent or tool = deny.

2

Check every action

A rule decides each tool call before it runs.

3

A record no one can rewrite

Signed, chained, checked offline. Any edit shows.

4

Humans who can stop it

Approve, escalate, stop. No answer = no action.

Four outcomes per action
DENY

Blocked. The agent gets the reason.

ESCALATE

A named person decides. No answer = no.

AUTO

Runs alone. Rules permit, all checks clean.

OBSERVE

Records only. Every new rule starts here.
